连接当前账号到 ChatGPT

              
为每个 ChatGPT 账号建立一个独立 Connector，并让名称与本软件里的账号配置档一致。不要让两个账号共用同一个 Tunnel ID。

              
    
                
  1. 确认当前配置档 — 的 MCP 与 Tunnel 都已就绪。切换账号不会停止另一个账号；每个账号可同时保持自己的 MCP/Tunnel 进程。
    2. 
                
  2. 打开 ，先在 Security and login 里开启 Developer mode。
    3. 
                
  3. 新建连接器，建议命名为 Web Harness · 当前账号。Connection 选择 Tunnel（不要填 localhost），在列表中选中当前配置档的 tunnel，或粘贴 Tunnel ID：
                  
    —
    
                
    4. 
                
  4. Authentication 保持默认，点击 Create → Connect。
    5. 
                
  5. 进入 Settings → Apps，找到这个应用，权限设为 Allow all actions / Never ask，否则 Goal 连续执行会被反复弹窗打断。
    6. 
                
  6. 新开一个对话，添加该应用，先发一条只读探针：请只读取工作区目录列表，不要修改任何文件。 看到工具卡片并返回本地文件列表即成功。
    7. 
                
  7. 第二个账号：回到本软件点 + 新账号 → 切换到新配置档 → 填写该账号自己的 Tunnel ID / Runtime API Key → 启动当前账号 → 在第二个 ChatGPT 账号里创建对应 Connector。无需关闭第一个账号。
