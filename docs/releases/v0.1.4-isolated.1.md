## ChatGPT Web Harness Isolated 0.1.4-isolated.1

Windows x64 隔离预览版。本次以独立版本发布，不替换稳定版的应用身份或数据目录。

### 改进
- 将状态进程查询改为带超时/输出上限的异步采集，避免同步阻塞主界面。
- 非日志页仅缓冲日志，减少隐藏视图 DOM 工作；返回后增量补齐。
- 修复 Skill 刷新/保存交错覆盖草稿，保留保存期间真正的新编辑。
- 独立身份、端口与数据/运行目录；禁止旧配置和密钥迁移，不接管、不复用、不终止外部服务。
- 移除安装器按进程名称全局终止逻辑，发布脚本默认禁止隐式上传。

### 下载与启动
下载 portable.exe 后直接运行；无需覆盖原版。默认 MCP / Admin / Tunnel 端口为 3300 / 3301 / 8380。数据目录为 %APPDATA%\chatgpt-web-harness-isolated。首次需自行填写工作区和 Tunnel 配置，请勿让原版和隔离版同时使用同一个 Tunnel ID。

### 验证
106/106 定向回归、根/desktop 全量测试、原生进程及真实 Electron UI 检查通过。Portable 直接解包后，23 个桌面源码文件和 2618 项运行 payload 与对应源产物一致。既有 Visual 浏览器退出测试曾偶发超时，保持原代码/断言进行定向及全量复跑通过；不声称已根治该波动。
