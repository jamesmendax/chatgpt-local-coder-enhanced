# 0.2.0 中文使用指南

## 选择安装形式

安装版会建立本产品的程序目录、快捷方式与卸载项；Portable 无须安装，双击即可。两种形式使用同一个独立产品数据目录，因此不应把二者当成两套账号隔离边界同时打开。账号隔离请使用应用内“+ 新账号”。

该独立版与旧原版使用不同产品身份、数据根和进程控制边界。不要覆盖正在承载连接的旧程序；并行运行时每套配置必须使用不同端口与工作区。独立版首次启动不会复制原版的密钥。

## 第一个配置档

打开“设置”，选择一个专用工作区，填入本账号的 Tunnel ID 与 Runtime API Key，再完成配置。凭据应从该账号实际可用的连接流程取得，不要使用示例值。检查 MCP、Admin、Tunnel 三个端口互不冲突。默认未配置时不会自动启动服务。

点击“启动当前账号”后，分别看 MCP 与隧道状态。MCP 健康仅说明本地服务可用；“本地链路已就绪”不代表云端授权已经完成。云端状态和实际账号工具调用也必须成功。具体 ChatGPT 连接入口以你账户当前提供的界面为准。

## 添加第二个配置档

在左侧“当前账号”区域点“+ 新账号”，使用容易区分的名称。新配置档有独立数据与运行目录，不会继承第一账号密钥。进入该账号的“设置”，填写它自己的 Tunnel ID / Runtime API Key、工作区与端口，然后完成配置。

工作区不能相同或互相包含；端口和 Tunnel ID 不能与其他配置档重复。先确认页面显示的是要操作的账号。启动 B 不会停止 A；切换下拉菜单仅改变当前控制目标，后台其他账号继续运行。配置正在运行时需要先停止对应账号再修改，不必停止其他账号。

## Skills / 插件

发行包默认没有预装 Skills。选择账号后进入“Skills / 插件”，安装可信的 Skill 目录或归档。安装、启停和卸载状态按账号区分；嵌套目录与同名文件的相对路径会保留。安装包中的代码仍会获得该账号被授权的本地能力，应先检查来源。

开发树中的示例 Skills 不等于发行包默认安装内容。桌面账号目录中的插件设置也不等于 ChatGPT 账户侧 App 权限；两者需要各自正确配置。

## 停止、关闭与数据

“停止当前账号”仅停止该配置档由本应用拥有的服务，不接管未知外部进程。退出应用会清理本应用管理的所有账号进程；启用了关闭到托盘时，关窗口不等于退出，请从托盘选择退出。

数据默认位于 %APPDATA%/chatgpt-web-harness-isolated；默认配置位于根目录，其他配置位于 accounts/<账号ID>。可以从界面中的运行目录入口定位文件。不要手动修改运行中的账号索引，也不要在运行时复制整个数据根作为第二账号。

卸载时程序文件与数据保留策略分开处理。本版静默卸载保留配置；人工删除数据必须先备份并核对目录，不能删除另一个产品或账号的数据。

## 故障定位

先确认当前账号名称、三个端口与日志归属。端口冲突时只修改受影响账号；不要全局结束所有 Node 进程。MCP 正常但隧道离线时检查本账号凭据、网络和云端状态，不把本地 ready 当作成功连接。配置拒绝重叠目录时为账号重新选互不包含的专用工作区。

向他人提交问题时，提供版本、脱敏日志和可复现步骤，不公开 Runtime API Key、Admin token、隧道私有连接信息或完整用户数据目录。

## 已知边界

本地双 MCP、账号切换、Skills 和包体操作的测试结果以随包 VALIDATION.json 为准；两个真实云端账号未使用真实凭据联机验收。软件未做代码签名，Windows 可能提示来源/信誉风险。此处没有承诺 OS 级隔离、永远免授权弹窗或平台自动唤醒。
